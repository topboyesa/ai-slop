I'm Sorry but Microsoft Copilot is shit

A year has gone-by ever since i used copilot for the first time and it complicated my code in a way that i have never seen before. I am a barebones html guy. I only write what is necesarry, if the code will run without the body tags, i prolly wouldn't write it. And I usually don't write it. Divs make things scary for me, let alone external CSS. But if you were learning programming you wouldn't even know how linking it works and it used to be a newbie's worst nightmare, ai probably writes it for you and links everything including the javascript. The more I write code and learn about new frameworks, the more i get blown away by centering a simple header on an unstyled page. Reminds me of something from the old days, a book, right? Simple plain back text over a white page. The OG theme.

All my headers are centralled by-the-way. It's crazy how it takes years of practice to master the basics. I have been programming since 2019. And I haven't been inspired to write my first hello world yet. Yes "hello world" is an application, written mostly over backends. I wrote my first in objective C during my first year in Computer Science Class. And I didn't understand it. Yes, so just generate your full-stack app and call yourself a full-stack programmer with networking knowledge so you hopefully land that help desk job. Honestly frontends alone are scary. Have you ever had the chance to design a fontend for an existing business? It is so crazy. They usually have existing themes and stuff so it's first limiting on the things you can try out. But hey ask them the requirements, start a project on claude, paste them and voila! A fully responsive UI in 3 minutes... No, it doesn't attach pictures so you'll have to do that on your own. But isn't that like the whole design? Pictures, I mean. I guess you have to design it yourself. Kind of defeats the purpose, doesn't it? The design thing?

So here we go again, I decide where to place the pictures and ai generates me an "acceptable webpage by todays standards with links scrolling to the same page, right?" Yes. Oh, wait? How do I see it? Luckily ai gives a preview. I guess that caused lots of problems, cos it was fixed pretty early. It is funny how non-programmers don't know about index.html files, and that you can view them on a browser. If I wrote sourcecode for the average client I would probably send it before payment because of how self-assuared I am that they wouldn't know how to handle it. So yea, barebones html shows elite level knowledge. Real programming ball.

Back to copilot. It writes some code, I have to change system variables. Install some things, lets say it got complex pretty quick. And I don't like complex stuff, easy does it. I later quit my project because of how complex it gets i just lose interest when I am scrolling down 400 lines of code for a single web-page. I know it doesn't affect speed but where is the elegance? Could you accomplish anything if you didn't have ai? what if you didn't have the internet to download packages and frameworks? What if you didn't have Visual Studio Code? What if you had to rely on the command line? That's where the real guys write.

On the positive side it is actually fun to build a full-stack app in 5 mins. Although I will lose interest in it in 5 mins. Real service doesn't require complexity. Just value. So spin up your apps. Write a simple blog in plain html and center a div or two. That is the real deal.
