"if the product is free then you're the product"

So I volunteered for a job. I wanted to build an app for a business that didn't need it for my portfolio. Hello recruiter.. Genarating apps with AI has become so much easier that I sometimes wonder how software developers are supposed to provide value. In some sense the sweat and blood involved in the process made it more valuable. I get it it is just perception. So, I got the job and did it till I burnt out. I go all out. At the end of it, bossman liked it. I wasn't impressed though. I knew I could do better, sometimes I feel that is my problem but maybe it is a feature. The self-doubt, it makes me constantly seek to improve in every task I try to do. I usually expect to be blown away by my work if it is good. Affirmations are good too, I won't try to downplay it. Reminds me of a quote, "It is not about the destination it is the journey." Whatever.

At the end of it, I was thinking about something more complex I could showcase on my portfolio. A win-win, maybe. Then I started enjoying going to work, a bit too much though. Problem is if you enjoy the work you forget about the people - co-workers that is. And it tends to cause problems, people feel like you're ignoring them and their endless stories. So some friction started to appear in my relationship with bossman. Turns out it is not liked if you're having a good time at work. Like you're supposed to be sad or something while working. Crazy. But in my free time I came up with a "notes-app", that turned out to be this blog. I write about my working journey with AI . Hopefully my writing is not bad and you like it. At least I won't be fired for nothing.

I might actually love working, I chose to do this after-all.

Feedback on this blog will be appreciated.

I'm Sorry but Microsoft Copilot is shit

A year has gone-by ever since I used Copilot for the first time, and it complicated my code in a way that I have never seen before. I am a barebones HTML guy. I write only what is necessary, if the code will run without the body tags, I probably wouldn't write it. And I sometimes don't. Divs alone make things hard for me, let alone external CSS. When I was learning programming, linking files was my worst nightware. Right now AI probably writes it for you and links everything including the JavaScript. The more I write code and learn about new frameworks, the more I get blown away by simple things such as centering a simple header by myself. Simple programs actually look better to me. Reminds me of something similar, a book, right? Simple plain black text over a white page. The OG theme.

It's crazy how it takes years of practice to master the basics. I have been programming for a while. I still write "hello world". At least I understand it now. It is funny how I can generate a full-stack application in an hour right now. Understanding it fully though will take some practice. Honestly frontends alone are so much work. Especially designing and building frontends for existing business? It is so crazy. Pre-conceived themes and styles are so limiting on the things you can try out.

Programming with AI has definitely improved from the first time I tried it, and by that I mean Claude. Copilot still feels complex. So here we go again, I decide where to place the pictures and AI generates me an "acceptable webpage by today's standards with links scrolling to the same page, right?" Preview and everything. It is funny how a regular non IT person doesn't know what index.html is. If I write code for a client they mostly don't know how to run it. So yea, maybe centering a div is some elite ball.

Back to Copilot. It generates some code, I change system variables... Install some things... then some more things I have to Install to make it work, it tells me my code can't work because of bugs. I copy paste the bugs it generates a fix, it doesn,t work. I redo it about 30 more times, then give up. I have never looked at the code again about a year later. The real quaestion is, would still be able to work without AI tools? What if you didn't have the internet to download packages and frameworks? What if you didn't have an IDE? What if you had to rely on the command line? That's where the real guys write.

On the positive side it is actually fun to build a full-stack app in 5 mins. Although you might lose interest in it in about 5 mins. Quality doesn't require complexity, just value.

So spin up apps and center a div or two.
